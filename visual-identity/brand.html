Bakehouse

A SQL Server workbench for macOS that brings its own instances.

The idea

Cold iron, hot ember. The interface is a dark, cool, neutral grey — the cast iron of an oven, not the warm clay of a bakery storefront. Heat appears in exactly one place: data that is live. An ember-colored element means something is running, connected, or about to change on disk. Everything else stays cool, so the eye finds state instantly across a window full of panels.

The mark is a hearth arch with three racks. Read one way it is an oven mouth. Read another it is the stacked discs of the standard database glyph. It holds both without saying either out loud, and it still reads at 16 pixels in a menu bar.

Instance states

The instance list is the front door of the app, so its status vocabulary is the most load-bearing color decision in the product. Each state pairs a hue with a distinct shape, so the list stays readable without color.

Editor

Six syntax colors, and ember is not among them. The cursor is the only ember thing in the editor, so it never competes with the status colors in the sidebar. 

-- restore a backup into a fresh instance
RESTORE DATABASE Northwind
FROM DISK = '/var/opt/mssql/backup/northwind_2024_full.bak'
WITH MOVE 'Northwind' TO '/var/opt/mssql/data/Northwind.mdf',
     MOVE 'Northwind_log' TO '/var/opt/mssql/data/Northwind.ldf',
     STATS = 5, REPLACE;

The mark at working sizes

The racks close up below about 14px, which is the floor. Below that, use the solid arch with no knockouts.

Rules

  • Ember means live. Primary action, running instance, active connection, cursor. If it is not one of those, it is not ember.
  • Gold means working. Pulling an image, restoring, proofing an instance. Gold is the only color allowed to animate.
  • Radius encodes hierarchy. 5px controls, 10px panels, 14px modals. Do not put one radius on everything.
  • State needs a shape. Filled dot, pulsing ring, hollow dot, triangle. Color alone is never the signal.
  • No Microsoft marks. Never put the SQL Server logo, the Microsoft name, or "SSMS" in the product name, icon, or window chrome. Compatibility goes in the description.
  • No bread. Wheat, rolling pins, chef hats and loaf illustrations turn a database tool into a café. The oven metaphor lives in the words and one arch, nowhere else.
  • No terracotta. Ember is a hot #FF5A1F against cool grey. Muting it toward clay collapses the temperature contrast the whole identity rests on.
